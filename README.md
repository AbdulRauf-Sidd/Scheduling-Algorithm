# Scheduling Algorithms

This repository contains implementations of various scheduling algorithms used in operating systems and computer science. These algorithms help in managing and optimizing the execution of processes in a system.

## Features

- **Priority Scheduling**: Implements priority-based scheduling where processes are executed based on their priority.
- **First-Come, First-Served (FCFS)**: Implements the FCFS scheduling algorithm where processes are executed in the order they arrive.
- **Round Robin**: Implements the round-robin scheduling algorithm with time slicing for fair process execution.
- **Shortest Job First (SJF)**: Implements the SJF scheduling algorithm where the process with the shortest execution time is selected next.

## Technologies Used

- **Python**: Used for implementing the scheduling algorithms.
- **Shell Scripting**: For interactive user input and execution of the algorithms.
